# Whale Musume Desktop

鲸鱼娘 Windows 桌面宠物。独立运行，不需要安装 DeepSeek Harness。

当前版本：**v2.3.1**

## 功能

- 透明置顶桌面宠物，仅显示系统托盘入口
- 多显示器、不同排列与分辨率下跨屏拖动
- 设置面板可拖动并记忆位置
- 投喂、戳一下、夸夸、分区摸头互动
- 两种小游戏、成长、签到、每日任务、称号和成就
- 89 个动作资源及按触发场景分组的动作预览
- 电脑状态联动：根据前台应用分类、CPU/内存、电池/电源和网络状态触发专属动作与随机台词，可在设置中总开关
- 宠物隐藏、安静模式、锁屏或挂起时暂停鼠标、空闲和电脑状态采样
- 前台应用支持 IDE、浏览器、办公、音乐、会议、终端、设计和游戏等分类
- 系统锁定、睡眠、恢复、全局键鼠空闲状态联动
- 天气感知：保留雨、雪、风粒子及天气动作，不绘制屏幕颜色蒙版
- 番茄钟、久坐、喝水和下班提醒，支持手动及定时安静模式
- 角色缩放、透明度与位置锁定
- 支持分别自定义主人称呼和桌宠名字，首次问候及后续台词会自动使用设置后的称呼
- 养成存档 JSON 导入导出（敏感天气 Key 不导出）
- 存档使用字段白名单、版本迁移和失败回滚，兼容旧版 v1 存档
- 低饱食自动反馈、投喂恢复和过量投喂降收益
- 待机眨眼使用单个多帧 WebP，保持完整睁眼—闭眼循环
- 随机自主走动使用分层二维骨骼生成的左右 16 帧多帧 WebP；走动期间锁定行走动作，场景动作延后至停下后播放
- 用户操作会打断当前移动，安静模式、位置锁定、设置面板和小游戏开启时自动停止走动
- 首次启动时复用行走序列从远处走近镜头，按由小到大的纵深入场后结合日期、星期和当前时间问候；减少动画时仅保留问候，安静模式下自动跳过
- 鼠标物理互动：快速拖放后带惯性滑行并在屏幕边缘弹回，绕着角色画圈会触发眩晕反馈
- 窗口栖息：可选地跟随最大化前台窗口，在窗口右上侧使用专属探头姿势停靠
- 设置中的养成数据、任务、称号与开关状态支持局部实时刷新，无需重开面板
- 托盘显示/隐藏、恢复位置、打开设置、开机启动和退出

## 环境

- Windows 10/11 x64
- Node.js 22.13 或更高版本
- npm

## 本地运行

```powershell
git clone https://github.com/xxli51/whale-musume-desktop.git
cd whale-musume-desktop
npm install
npm start
```

## 测试

```powershell
npm test
```

完整开发门禁（语法、Lint、格式、测试和依赖审计）：

```powershell
npm run verify
```

生成测试覆盖率：

```powershell
npm run test:coverage
```

检查当前多显示器虚拟桌面范围：

```powershell
npm run qa:display
```

## 打包 Windows EXE

免安装便携版：

```powershell
npm run build:portable
```

也可以直接双击项目根目录的 `build-portable.bat`，脚本会检查 npm、项目文件和依赖后执行便携版构建。

安装版：

```powershell
npm run build
```

产物位于 `dist/`。项目未附带商业代码签名证书，下载后的 EXE 可能触发 Windows SmartScreen 提示。

## 使用

- 拖动鲸鱼娘：按住角色移动，可跨显示器。
- 打开完整设置：右键鲸鱼娘，或右键托盘图标选择“设置与动作”。
- 移动设置面板：拖动顶部蓝色标题栏。
- 完全退出：右键托盘图标选择“退出”。
- 查看本地诊断日志：右键托盘图标选择“打开诊断日志目录”。
- 电脑状态联动仅读取前台程序进程名用于分类，不读取窗口标题、键盘输入、文件或网页内容。
- CPU/内存持续高于阈值才会提醒，各类联动带有冷却时间，避免频繁弹出台词。

## 项目结构

```text
assets/       角色图片、动画表现层与状态机
build/        Windows 应用图标
renderer/     桌面窗口、设置、存储模型与设置数据模块
runtime/      可独立测试的主进程运行策略与本地诊断
tools/        显示器范围诊断与走路动画构建工具
test/         仓库完整性与核心行为测试
main.cjs      Electron 主进程与托盘、多屏逻辑
preload.cjs   安全的渲染进程桥接层
```
